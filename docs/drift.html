How long can a bad reading go unnoticed?

A machine learns what zero and one sound like by measuring quantum bits in known states. Later, the signal shifts. Using the old reference, the machine can mistake a one for a zero and leave a bit untouched when it needs a flip.

Watch two controllers face the same sudden shift. One keeps its original reference. The other checks known bits periodically. Scrub forward to see how many measurements slip through before the next check catches the change.

Why study this?

Experiments on superconducting hardware have measured the readout speed–accuracy tradeoff and used recalibration to counter control drift. This demo isolates those concerns with a synthetic phase shift and an illustrative deadline.
